# Agent Brief — road_municipalities_col

This repo is public and accompanies an academic paper. It documents the comparison of Overture Maps road network data against Colombian municipality and urban zone (cabecera) boundaries. Everything here must be clean, reproducible, and well-documented for an outside reader.

### `src/1_combine_boundaries.py`

Produces a single non-overlapping zones GeoDataFrame covering all selected municipalities,
split into rural (municipality minus its cabecera) and cabecera (urban zone) parts.

**Key data facts:**

- `data/boundaries/cabeceras/MGN_URB_ZONA_URBANA.shp`
  - CRS: EPSG:4686
  - 7793 rows total; filter to `clas_ccdgo == "1"` → 1103 rows (main cabeceras only, excludes satellite zones)
  - Key columns: `mpio_cdpmp` (5-char string, e.g. `"05001"`), `clas_ccdgo`

- `data/boundaries/municipios/` (MGN_MPIO_POLITICO shapefile)
  - CRS: likely EPSG:4686 (verify on load)
  - Key columns expected: `mpio_ccnct` (5-char municipality DIVIPOLA code), `dpto_cnmbr`, `mpio_cnmbr`

- `data/municipios_sel.csv`
  - 698 rows, columns: `ID` (int64), `municipio`, `departamento`
  - **Critical:** IDs are stored as integers (e.g. `5001`). Must zero-pad to 5 chars before any merge:
    ```python
    sel["ID"] = sel["ID"].astype(str).str.zfill(5)  # → "05001"
    ```
  - `mpio_cdpmp` in cabeceras is already a 5-char string — no padding needed there.

**Logic:**

1. Load municipios, reproject to EPSG:3116 (Colombia West, metric — use for all length calculations)
2. Filter to selected municipalities by merging with `municipios_sel.csv` on `mpio_ccnct` == `ID` (after zero-padding)
3. Load cabeceras, filter `clas_ccdgo == "1"`, reproject to EPSG:3116
4. For each selected municipality, dissolve its cabecera polygons and subtract:
   ```python
   rural_geom = municipality_geom.difference(dissolved_cabecera_union)
   ```
   If a municipality has no matching cabecera, use its full polygon as rural.
5. Build two GeoDataFrames with a common schema and concatenate:
   - `mun_rural`: `zone_type = "rural"`, key col `mpio_id` (from `mpio_ccnct`)
   - `mun_cabecera`: `zone_type = "cabecera"`, key col `mpio_id` (from `mpio_cdpmp`)
   - Common columns: `mpio_id`, `municipio`, `departamento`, `zone_type`, `geometry`

**Output:** `data/outputs/zones_combined.gpkg`

Print a summary: number of rural zones, number of cabecera zones, any municipalities with no matching cabecera.

### `src/2_audit_road_classes.py`

Loads the Overture parquet, computes road lengths, and reports the raw class distribution.
This output informs whether any class consolidation is needed (decided separately with the client).

**Logic:**

1. Load `data/overture/roads_colombia_mainland_segments.parquet`
2. Reproject to EPSG:3116
3. Lowercase all column names
4. Filter `subtype == "road"`
5. Keep columns `["id", "class", "geometry"]`, compute `length = geometry.length`
6. Group by `class`, compute: segment count, total length in metres, total length in km, % share of total
7. Print table and save to `data/outputs/overture_class_audit.csv`

Expected Overture `class` values include (but verify against actual data): `motorway`, `trunk`,
`primary`, `secondary`, `tertiary`, `residential`, `service`, `track`, `path`, and others.

### `src/3_clip_and_aggregate.py`

Clips the Overture roads to each zone (rural / cabecera) and reports raw lengths per Overture class.
**No class consolidation** — raw `class` values from Overture are reported as-is.

**Logic:**

1. Load `data/outputs/zones_combined.gpkg` (output of script 1)
2. Load Overture roads (same prep as script 2: filter subtype, reproject, compute length)
3. Clip using a spatial-index-accelerated loop — **single pass over all zones combined** (rural + cabecera are non-overlapping, so one clip covers everything):

```python
def clip_roads_to_zones(roads, zones):
    roads_sindex = roads.sindex
    results = []
    for _, zone in zones.iterrows():
        idx = list(roads_sindex.intersection(zone.geometry.bounds))
        candidates = roads.iloc[idx]
        intersecting = candidates[candidates.intersects(zone.geometry)]
        if not intersecting.empty:
            clipped = intersecting.copy()
            clipped.geometry = clipped.geometry.intersection(zone.geometry)
            clipped = clipped[~clipped.geometry.is_empty]
            for col in ["mpio_id", "municipio", "departamento", "zone_type"]:
                clipped[col] = zone[col]
            results.append(clipped)
    return gpd.GeoDataFrame(pd.concat(results, ignore_index=True), crs=roads.crs)
```

4. After clipping, recalculate `length = geometry.length` (clipped geometry is shorter than original)
5. Aggregate: group by `["mpio_id", "municipio", "departamento", "zone_type", "class"]` → `sum(length)` → `total_length_m`
6. Export:
   - `data/outputs/overture_roads_by_class.csv` — columns: `mpio_id`, `municipio`, `departamento`, `zone_type`, `class`, `total_length_m`
   - `data/outputs/overture_roads_clipped.gpkg` — clipped road segments with columns: `id`, `class`, `zone_type`, `mpio_id`, `length`, `geometry`

The GPKG can be opened in QGIS to visually verify that rural and cabecera segments do not overlap.
