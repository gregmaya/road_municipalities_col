# Design — road_municipalities_col

**Date:** 2026-04-16
**Purpose:** Academic repo accompanying a paper. Contains an audit of Overture Maps road data filtered to the municipalities in the study, reporting road length by Overture class and DANE zone type. Must be clean, reproducible, and self-contained for outside readers.

---

## 1. Data sources

| Asset | File | CRS | Notes |
|---|---|---|---|
| Overture roads | `data/overture/roads_colombia_mainland_segments.parquet` | EPSG:4326 (geographic) | Release 2025-07-23; already present, do not re-download |
| DANE MGN2018 Integrado con CNPV2018 — Clase Censal | `data/dane_mgn/SHP_MGN2018_INTGRD_CLASECS/MGN_ANM_MPIOCL.shp` | EPSG:4686 (MAGNA-SIRGAS) | Downloaded 2026-04-16 from https://www.dane.gov.co/files/geoportal-provisional/ |
| Selected municipalities | `data/municipios_sel.csv` | n/a | 698 rows; `ID` (int), `municipio`, `departamento` |
| Metadata PDF | `data/dane_mgn/MGN2018_Integrado_CNPV2018_InstructivoUso.pdf` | n/a | Official DANE usage guide for the integrated dataset |
| Data dictionary | `data/dane_mgn/SHP_MGN2018_INTGRD_CLASECS/Diccionario_Datos_Niveles_Variables_MGN_CNPV2018Int.xlsx` | n/a | Column definitions for MGN_ANM_MPIOCL |

### MGN_ANM_MPIOCL key fields

| Column | Type | Description |
|---|---|---|
| `MPIO_CDPMP` | String(5) | 5-char DIVIPOLA municipality code (e.g. `"05001"`) |
| `DPTO_CCDGO` | String(2) | 2-char department code |
| `CLAS_CCDGO` | String(1) | Zone class: `"1"` = Cabecera Municipal, `"2"` = Centro Poblado, `"3"` = Rural Disperso |
| `MPIO_CLASE` | String(22) | Composite code (MPIO_CDPMP + CLAS_CCDGO) |

**Record counts (full national dataset):** 1,102 cabeceras + 931 centros poblados + 1,122 rurales = 3,155 total across 1,122 municipalities.

**Key fact:** Zones are already pre-cut — no geometry differencing is required.

## 2. Zone classification

Three `zone_type` values map directly to DANE's classification:

| `CLAS_CCDGO` | `zone_type` | Meaning |
|---|---|---|
| `"1"` | `cabecera` | Main urban nucleus (Cabecera Municipal) |
| `"2"` | `centro_poblado` | Secondary urban nucleus (Centro Poblado) |
| `"3"` | `rural` | Dispersed rural area |

---

## 3. Projection convention

**All geometry operations use EPSG:3116** (MAGNA-SIRGAS / Colombia Bogotá, metric). Every script reprojects its inputs to EPSG:3116 immediately on load. This is the single working CRS for length calculations and spatial joins.

## 5. Script specifications

### `src/0_download_overture.sh` (reference only)

A bash script documenting how the Overture parquet was originally downloaded. Contains a comment making clear this must not be re-run (data already present). No changes from original BRIEF.

```bash
#!/bin/bash
# Reference only — roads_colombia_mainland_segments.parquet is already present in data/overture/
# Bounding box covers Colombia mainland (excluding islands).
# Release date is pinned for reproducibility; update --release to re-download a newer version.
# Requires: pip install overturemaps

overturemaps download \
  --bbox=-79.00806,-4.22694,-66.85028,12.45833 \
  --release=2025-07-23 \
  -f geoparquet \
  --type=segment \
  -o data/overture/roads_colombia_mainland_segments.parquet
```

### `src/1_audit_road_classes.py`

Loads the Overture parquet, reprojects, and reports the raw class distribution. Output informs any class consolidation decisions (made separately with the researcher).

**Steps:**
1. Load `data/overture/roads_colombia_mainland_segments.parquet`
2. Reproject to EPSG:3116
3. Lowercase all column names
4. Filter `subtype == "road"`
5. Keep `["id", "class", "geometry"]`, compute `length = geometry.length`
6. Group by `class` → segment count, total length (m), total length (km), % share of total
7. Print table; save to `data/outputs/overture_class_audit.csv`

**Output:** `data/outputs/overture_class_audit.csv`
Columns: `class`, `segment_count`, `total_length_m`, `total_length_km`, `pct_share`

### `src/2_clip_and_aggregate.py`

Loads both data sources directly, clips roads to zones, and aggregates by zone and road class.

**Steps:**

**Zone loading:**
1. Load `data/dane_mgn/SHP_MGN2018_INTGRD_CLASECS/MGN_ANM_MPIOCL.shp`, reproject to EPSG:3116
2. Load `data/municipios_sel.csv`; zero-pad `ID`: `sel["ID"] = sel["ID"].astype(str).str.zfill(5)`
3. Merge shapefile on `MPIO_CDPMP == ID` to filter to 698 selected municipalities
4. Map `CLAS_CCDGO` → `zone_type`: `{"1": "cabecera", "2": "centro_poblado", "3": "rural"}`
5. Retain columns: `mpio_id` (from `MPIO_CDPMP`), `municipio`, `departamento`, `zone_type`, `geometry`
6. Print zone summary: count per `zone_type`, municipalities missing any zone type

**Road loading:**
7. Load `data/overture/roads_colombia_mainland_segments.parquet`, reproject to EPSG:3116
8. Lowercase column names; filter `subtype == "road"`; keep `["id", "class", "geometry"]`
9. Compute `length = geometry.length`

**Clip (spatial-index-accelerated, single pass):**
```python
def clip_roads_to_zones(roads, zones):
    roads_sindex = roads.sindex
    results = []
    for _, zone in zones.iterrows():
        idx = list(roads_sindex.intersection(zone.geometry.bounds))
        candidates = roads.iloc[idx]
        intersecting = candidates[candidates.intersects(zone.geometry)]
        if not intersecting.empty:
            clipped = intersecting.copy()
            clipped.geometry = clipped.geometry.intersection(zone.geometry)
            clipped = clipped[~clipped.geometry.is_empty]
            for col in ["mpio_id", "municipio", "departamento", "zone_type"]:
                clipped[col] = zone[col]
            results.append(clipped)
    return gpd.GeoDataFrame(pd.concat(results, ignore_index=True), crs=roads.crs)
```

**Post-clip:**
10. Recalculate `length = geometry.length` on clipped geometry
11. Aggregate: group by `["mpio_id", "municipio", "departamento", "zone_type", "class"]` → `sum(length)` → `total_length_m`

**Outputs:**
- `data/outputs/overture_roads_by_class.csv` — columns: `mpio_id`, `municipio`, `departamento`, `zone_type`, `class`, `total_length_m`
- `data/outputs/overture_roads_clipped.gpkg` — columns: `id`, `class`, `zone_type`, `mpio_id`, `length`, `geometry`

The GPKG can be opened in QGIS to verify that zones do not overlap.

## 7. General constraints

- All paths are relative from repo root (e.g. `data/outputs/overture_roads_by_class.csv`)
- Print progress messages at each major step
- Scripts are self-contained — no shared `utils.py`
- No visualisation/plotting code
- Scripts run in order: 1 → 2 (script 2 uses data from Overture and the MGN shapefile directly; no intermediate zone file)
